Eight prompts to write prompts

Run each one in a Gemini Gem. Paste what the Gem writes back into the box underneath it. I read the boxes, compare each against the prompt I wrote for the same agent, and take whatever the Gem got right.

None of these contains my answer. Each one gives Gemini the same raw material I had — the job, who it is for, what the output feeds — and nothing about how I solved it. If a meta-prompt listed my rules, the Gem would hand them back in its own words and the comparison would prove nothing. So the constraints appear as facts about the problem, and the Gem has to derive the rules itself. What is worth copying is a rule I missed, or one of mine with a better reason behind it. A longer prompt is not a better one.
