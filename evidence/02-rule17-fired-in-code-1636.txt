--- WHAT THIS PROVES ---------------------------------------------------------
This is the NothingRetrieved? decision in AgentFlow, added 9 November. When the
retrieved passage count is zero the flow returns BEFORE BuildMessages and
BEFORE the agent is called. No board, no tokens, no memory.

Until that step existed, rule 17 was PROMPT WORDING ONLY. Mentor's own words
when asked: "That is an instruction in the prompt, not a check in the flow. The
flow counts the passages but never uses the count to stop the model call."

That is the exact failure rule 17 describes in its own text: an agent whose
retrieval returned nothing does not error, it writes a confident, plausible
board out of training data, and nothing downstream can tell the difference.

BOTH the code check and the prompt rule are kept. They catch different
failures: code catches "nothing was retrieved"; only the model can judge
"passages were retrieved but none support the practice I want to use".
