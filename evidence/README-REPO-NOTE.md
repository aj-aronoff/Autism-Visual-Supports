# A note on this directory being public

**These are the run records: what was actually sent, what came back, and what the numbers were.**
They are here because a claim a judge cannot chase is worth very little, and because the honest
half — `README.md`'s section on what this directory does **not** prove — is as much the point as
the results.

**Two redactions, and only two:**

- `05-retrieval-scores.md` described a column header from the National Standards report instead
  of quoting it. The source document is not ours to republish.
- `07-portal-readings.md` withholds the endpoints and key names of eleven library settings that
  arrived with the agentic app template. **No key value appears anywhere in this repository**, and
  none of those libraries is called by this application.

**The source documents themselves are not in this repository** and never have been. The TRIAD
toolkit's own credits permit distribution as an electronic file, which is what allows it to sit in
a knowledge base; that permission is not a licence for us to re-host it here.
